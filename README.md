# macOS

The `macbook` nix-darwin configuration shares zsh, oh-my-zsh (agnoster and
plugins), autosuggestions, syntax highlighting, and fzf with the NixOS hosts.
It also shares a Neovim configuration with line numbers enabled. The
Nix-managed Neovim startup configuration replaces the normal
`~/.config/nvim/init.vim` or `init.lua`; extend `neovim.nix` to customize it.
It uses the existing macOS user and leaves `~/.zshrc` and `~/.zprofile` in
place; their settings can override the system configuration. Agnoster requires
a Powerline-compatible terminal font.

With Nix and flakes already enabled, build the configuration first:
Git-backed flakes only include tracked or staged files, so stage new `.nix`
files before running these commands.

```sh
nix build .#darwinConfigurations.macbook.system
```

Inspect the existing `/etc/zshrc`, `/etc/zprofile`, and `/etc/nix/nix.conf`
before the first switch: nix-darwin manages system files and may require
backing up conflicting files. Then install using the flake's pinned
nix-darwin:

```sh
sudo nix --extra-experimental-features 'nix-command flakes' run .#darwinConfigurations.macbook.config.system.build.darwin-rebuild -- switch --flake .#macbook
```

For later changes, run `sudo darwin-rebuild switch --flake .#macbook`.
Open a new interactive zsh to load the configuration.

On the NixOS hosts, an old `~/.zshrc` generated by the previous configuration
may still initialize fzf. Remove that line if present to avoid loading it twice;
the shared system configuration now initializes fzf without overwriting the
file.
